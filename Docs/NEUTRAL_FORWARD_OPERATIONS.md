# Neutral Forward Operations and Deployment Readiness

AMRTE v0.26.0 provides a forward-only operational harness for generic offline
workflow research. It does not perform or simulate market participation.

Implemented controls include sequential validation promotion, material-change
classification, immutable forward observations, point-in-time eligibility,
neutral drift monitoring, bounded soak records, environment identity,
single-instance protection, pause/resume governance, health heartbeats, clock
and storage restrictions, backup manifests, restore verification, deterministic
replay, recovery, reconciliation, audit, and DecisionTrace.

Deployment locations are configurable relative paths. The service architecture
is suitable for an unattended process manager, but no Windows service is
installed automatically. Native Windows Server testing remains outstanding.

Automatic promotion and automatic retuning are prohibited. A healthy readiness
scorecard remains `HOLD` until a governed manual approval advances one adjacent
research stage. Operational failures can only preserve or reduce permission.

The module contains no broker, account, order, position, monetary outcome,
leverage, margin, wagering, or financial execution interface.
